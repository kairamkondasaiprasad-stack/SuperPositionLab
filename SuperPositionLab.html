Superposition Theorem

Find the response of a linear network with several independent sources by working with one source at a time.

In a linear bilateral network with more than one independent source, the current through or voltage across any element equals the algebraic sum of the values each source produces alone.

  • Keep one source, replace each other voltage source with a short circuit
  • Replace each other current source with an open circuit
  • Add the partial currents with their signs: IL = IL′ + IL″

Learning Mode

Open each step in order, then use the formula sheet below.

Step 1 – Check the network is linear

Superposition works only for linear circuits: resistors, independent sources and linear dependent sources. It does not work for power, because power depends on the square of current.

Step 2 – Pick one source and turn off the rest

An ideal voltage source has zero voltage when turned off, so replace it with a wire. An ideal current source carries zero current when turned off, so replace it with a break.

Step 3 – Solve the simpler circuit

With V2 shorted, R2 and RL are in parallel, and that pair is in series with R1. Use the voltage divider to find VA, then IL′ = VA / RL.

Step 4 – Repeat for every other source

Do the same with V1 shorted: now R1 and RL are in parallel, in series with R2. This gives IL″.

Step 5 – Add with signs

IL = IL′ + IL″. If a partial current flows against the direction you chose for IL, it enters the sum as a negative number.

Formula sheet

Ohm’s law

Voltage across a resistor is proportional to the current through it.

V = I × R

I = V / R   R = V / I

P = V × I = I² × R = V² / R

Kirchhoff’s Current Law (KCL)

The currents entering a node equal the currents leaving it.

Σ Iin = Σ Iout (or Σ I = 0)

At node A: I1 + I2 = IL

Kirchhoff’s Voltage Law (KVL)

The voltages around any closed loop add up to zero.

Σ V = 0 (around a closed loop)

V1 − I1R1 − ILRL = 0

Series and parallel resistors

Series resistors add. Parallel resistors share the same voltage.

Series: Req = R1 + R2

Parallel: 1/Req = 1/R1 + 1/R2

Two in parallel: Req = R1R2 / (R1 + R2)

Voltage and current dividers

Used in each superposition case to find VA and the load current.

Voltage divider: VR1 = V × R1 / (R1 + R2)

Current divider: I1 = I × R2 / (R1 + R2)

Superposition formulas

Used in this simulator.

IL = IL′ + IL″

VA′ = V1 × (R2∥RL) / (R1 + R2∥RL)

Check: VA = (V1/R1 + V2/R2) / (1/R1 + 1/R2 + 1/RL)
